=============================================================================
  HOW TO ADD YOUR IMAGES TO THIS PORTFOLIO
=============================================================================

This directory (`assets/images/`) is where you place all your photos and screenshots.

1. PROFILE PHOTO:
   - File name: `profile.jpg` (or change extension in index.html to .png)
   - Recommended size: Square (e.g. 500x500 px or 800x800 px)
   - When added, it will automatically appear inside the 3D spinning avatar ring on the home section!
   - If missing, the website automatically falls back to your stylish "SS" monogram initials.

2. PROJECT 1 PREVIEW (FixMyCity):
   - File name: `project-fixmycity.png` (or .jpg)
   - Recommended size: 16:9 ratio (e.g. 800x450 px or 1200x675 px)
   - If missing, it automatically displays the built-in civic web SVG banner.

3. PROJECT 2 PREVIEW (C++ E-Commerce):
   - File name: `project-ecommerce.png` (or .jpg)
   - Recommended size: 16:9 ratio (e.g. 800x450 px)
   - If missing, it automatically displays the built-in terminal console preview.

4. RESUME (PDF):
   - You can also place your resume here: `assets/resume.pdf`
   - Update the "Request Resume" link in index.html to point to `assets/resume.pdf` with `download` attribute if you want direct download!

5. FAVICON:
   - `favicon.svg` is already set up and linked in `index.html`.
=============================================================================
